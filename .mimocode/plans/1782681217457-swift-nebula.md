# Plan: Informe Técnico-Comercial Docu-Intel en PDF

## Objetivo
Generar un informe completo en PDF de la aplicación Docu-Intel, con enfoque tanto técnico (para equipotécnicos) como comercial (para jefes/dirección), usando HTML estilizado convertido a PDF.

## Enfoque: HTML → PDF
1. Crear un archivo HTML con CSS embebido para maquetación profesional
2. Usar el navegador Chromium (via `npx playwright chromium` o `node` con puppeteer) para convertir HTML a PDF
3. Alternativa: usar `python -m weasyprint` o un script Node con `html-pdf`

## Estructura del Informe

### Portada
- Título: "Docu-Intel — Sistema de Inteligencia Documental"
- Subtítulo: "Informe Técnico y Comercial"
- Fecha, versión

### 1. Resumen Ejecutivo (Comercial)
- Qué es Docu-Intel en 1 párrafo
- Problema que resuelve
- Valor para el negocio

### 2. Capacidades Principales (Comercial + Técnico)
Organizado por功能:
- **Ingesta automática**: watcher 24h, carpetas, subida web, API
- **OCR multicascada**: Tesseract → PaddleOCR → PP-Structure con preprocesado
- **Extracción de datos**: presupuestos, pedidos, facturas, planos
- **Búsqueda inteligente**: textual + semántica + híbrida (RRF)
- **Chat IA local**: preguntas en lenguaje natural con fuentes verificables
- **Planos y cotas**: escala, habitaciones, geometría, acotaciones
- **Administración y gobierno**: alertas, auditoría, calidad, aprendizaje IA
- **Integraciones**: API externa con aislamiento por presupuesto

### 3. Casos de Uso (Comercial)
- "Buscar un presupuesto por número"
- "¿Cuánto hemos gastado en el hotel X?"
- "Revisar documentos de baja calidad OCR"
- "Consultar medidas de un plano"
- "Integrar con herramienta externa de gestión"

### 4. Arquitectura General (Técnico)
- Diagrama de componentes (texto ASCII o tabla)
- Servicios Docker: backend, frontend, postgres, redis, workers (fast/heavy/GPU/maintenance), watcher, scheduler
- Flujo de datos: ingesta → OCR → embeddings → búsqueda → IA

### 5. Stack Tecnológico (Técnico)
Tabla de tecnologías:
- Backend: FastAPI, Python 3.11, Celery, SQLAlchemy, Alembic
- Frontend: React 18, Vite, TypeScript, Tailwind CSS, TanStack Query
- Base de datos: PostgreSQL 16 + pgvector
- Cache/Colas: Redis 7
- OCR: Tesseract 5, PaddleOCR 3.5, PP-Structure, OpenCV
- IA: sentence-transformers (Granite/BGE-M3), LLM local (Qwen2.5)
- Infra: Docker, NVIDIA GPU (2× RTX 4070), LM Studio
- Monitoreo: Sentry/GlitchTip, Prometheus

### 6. Pipeline OCR y Preprocesado (Técnico)
- Cascada de 3+1 motores con score de calidad
- Preprocesado específico por motor (deskew, DPI, denoise)
- Gestión de GPU workers separados
- Calidad: scoring por confianza, densidad alfanumérica, longitud

### 7. IA y Recuperación (Técnico)
- Chunking semántico con metadatos
- Embeddings: BGE-M3 (1024 dims), query vs passage mode
- Búsqueda híbrida con RRF (Reciprocal Rank Fusion)
- Reranker cross-encoder
- Agent con 15+ tools internas
- Learning loop: propuestas → aprobación → patrones aprendidos

### 8. Seguridad y Permisos (Técnico)
- RBAC: admin, gestor, operario
- Aislamiento por presupuesto/budget_scope
- API keys + sesiones firmadas
- Redacción de precios para operarios
- Auditoría completa de acciones

### 9. Infraestructura y Despliegue (Técnico)
- Docker Compose (dev + prod)
- Workers separados por carga
- GPU: 2× RTX 4070, CUDA por worker
- Backup: PostgreSQL + files + Redis
- CI/CD: GitHub Actions
- Healthchecks en todos los servicios

### 10. Base de Datos (Técnico)
- Modelos principales: documents, chunks, budgets, orders, plans, users
- pgvector para embeddings
- Auditoría: audit_logs
- Learning: classification_suggestions, learned_patterns

### 11. Roadmap y Fases
- Fase 1: Ingesta + OCR básico
- Fase 2: Extracción presupuestos/pedidos
- Fase 3: Embeddings + búsqueda semántica + chat IA
- Fase 4: Planos y cotas
- Fase 5: Operación, alertas, integraciones, aprendizaje

### 12. Métricas de Calidad
- Estados de calidad: processed_ok, processed_low_quality, needs_human_review
- Dashboard de métricas y readiness
- Alertas automáticas

## Archivos a Crear

## Generación del PDF
Usar Puppeteer (o playwright) para renderizar el HTML a PDF:
```bash
cd docu-intel
npm install puppeteer  # o usar playwright ya instalado
node docs/generate-pdf.js
```
Resultado: `docu-intel/docs/Docu-Intel_Informe_Tecnico_Comercial.pdf`
